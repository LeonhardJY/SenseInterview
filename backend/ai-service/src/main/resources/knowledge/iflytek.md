# 科大讯飞 · Java 开发工程师面试真题

> 来源：牛客面经《2025/09/05 科大讯飞 Java开发工程师一面》
> 岗位：Java 开发工程师（55 分钟，无手撕）
> 流程：投递 → 测评 → 笔试 → 一面

## 一面面试问题

### 数据结构
- 常见数据结构有哪些？从大的维度讲，比如数据结构包括哪些大类，每类下面有哪些细分
- 提示：线性数据结构（数组、链表、栈、队列）、树、图、哈希等

### Java 集合
- Java 里的集合你是怎么理解的？怎么划分、怎么设计的？每个具体集合的常用实现类有哪些
- List 的实现里 ArrayList 和 LinkedList，哪个是线程安全的
- 如果要把 LinkedList 变成线程安全的，怎么实现
- Map 结构里如果想实现排序，怎么做

### 并发与线程
- 线程的状态有哪些
- 哪些场景下一个运行状态的线程会变成阻塞状态
- JUC 是什么？JUC 包里用于多线程并发和同步的典型实现类有哪些（信号量，还有哪些）
- 线程池：一个线程执行完一个任务后处于什么状态

### 设计模式
- 项目中有 A、B、C 三种实现方案，基于同一套算法流程，只是每步具体实现不同，该用什么设计模式
- 策略模式是什么样子的

### Redis
- 项目中 Redis 使用的什么版本
- Redis 常见数据类型有哪些
- 布隆过滤器知道吗？主要解决什么场景的问题
- 布隆过滤器底层是怎么实现的
- 布隆过滤器解决大量数据快速判断真阴性和假阳性的问题，这个场景还有没有更优的方案

### 其他
- 自我介绍、在校成绩和竞赛情况、项目来源
- 面试官追问：多线程场景下的其他更优方案
