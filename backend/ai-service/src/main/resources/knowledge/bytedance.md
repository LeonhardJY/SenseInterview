# 字节跳动 · 后端面试真题

> 来源：面试狗《字节跳动后端工程师面试准备》
> 岗位：后端开发工程师（Java/Go）
> 面试会结合内容推荐、短视频增长、国际化业务和高并发业务场景追问

## 一面：语言基础与数据库
- Java 或 Go 基础，集合与并发
- JVM 或协程
- MySQL 索引、事务
- Redis 数据结构
- 常见算法题

## 二面：中间件与系统设计
- 高并发、缓存一致性、消息队列、分布式锁、限流降级、幂等、事务一致性、服务治理
- 接口设计、容量评估、故障恢复、链路追踪、灰度发布、数据一致性和成本优化

## 高频面试题 Top 5

### 1. Redis 分布式锁如何设计才可靠
- 需要使用唯一 token、原子加锁、Lua 原子释放、合理过期时间和续期机制
- 高可靠场景还要讨论 RedLock 争议、业务幂等和锁失效补偿

### 2. MySQL 索引为什么会失效
- 对索引列做函数或隐式转换、最左前缀不满足、范围查询后列无法继续利用
- 低选择性字段、统计信息不准、优化器选择全表扫描

### 3. 如何保证消息队列消费幂等
- 业务唯一键、去重表、状态机、乐观锁或 Redis setnx 控制重复处理
- 让下游写操作具备幂等语义，保留补偿和重试机制

### 4. 高并发秒杀系统怎么设计
- 前置限流、库存预热、请求削峰、缓存扣减、异步下单、幂等防重、最终一致性和热点隔离
- 监控库存、队列堆积和失败补偿

### 5. 内容流首屏性能如何优化
- 缓存、接口聚合、CDN、预取、渲染优化等思路
