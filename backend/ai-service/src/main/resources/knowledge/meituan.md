# 美团 · 后端开发面试真题

> 来源：牛客面经《美团核心本地商业业务研发平台-后端开发-1面》
> 岗位：后端开发工程师（Java）
> 特点：项目拷打密集，围绕缓存、秒杀、Redis 集群层层深挖

## 缓存与一致性
- 项目中为什么要考虑使用 caffeine + Redis 本地缓存的方案？数据一致性如何保证
- 既然 Redis 能支持高并发，为什么还需要一个 caffeine 本地缓存
- 不采用本地缓存的前提下，查询热点数据的场景有什么支持高并发的方案
- 查询场景下使用消息队列存请求的话，结果如何返回给请求方
- canal 中间件监听 binlog，如何得到结果，结果如何返回
- caffeine 本地缓存的数据结构和具体内容是什么

## Redis 集群
- 不采用本地缓存的前提下，查询热点数据采用"集群"方案了解吗
- Redis 集群负责写请求的只有主节点，写压力大有什么解决方案
- Redis 集群能分摊高并发下的请求压力吗

## 秒杀优惠券场景深挖
- 秒杀优惠券场景下，Redis 的 key 和 value 分别存了什么
- 用户抢券的完整流程，访问了哪些数据
- 查询场景中会出现什么热点问题吗
- 可能面临缓存击穿的情况下，秒杀优惠券是否使用了缓存
- 秒杀成功后订单已生成，优惠券库存发生变化时，Redis 和 caffeine 更新缓存的机制
- 集群场景下，优惠券库存变化时，其他机器的 caffeine 本地缓存如何更新
- 除了缓存，还调研过哪些其他方案
