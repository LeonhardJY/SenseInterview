# 阿里巴巴 · Java 后端面试真题

> 来源：牛客面经复盘 / 阿里云开发者社区「面小易」系列
> 岗位：Java 后端开发工程师（技术一面/二面/交叉面）

## 技术一面

### Java 基础与集合
- HashMap 底层原理、扩容机制（为什么是 2 的幂次扩容）、为什么线程不安全
- ConcurrentHashMap 如何保证线程安全？JDK7 与 JDK8 实现有何区别
- ThreadLocal 原理、为什么会有内存泄漏问题、如何解决

### JVM
- JVM 内存模型，堆和栈的区别，什么情况下发生 StackOverflowError 和 OOM
- 常见垃圾回收算法有哪些？CMS 和 G1 的区别？线上 Full GC 频繁如何排查

### 并发
- synchronized 和 ReentrantLock 的区别？AQS 原理了解吗
- 用过哪些并发工具类？CountDownLatch 和 CyclicBarrier 的区别

### 项目拷问（订单系统）
- 为什么要重构订单系统？原系统有什么问题
- 分表如何做？分片键如何选择？如何保证一致性
- 分布式事务：AT 模式和 TCC 模式的区别与适用场景

## 技术二面

### 系统设计
- 设计一个秒杀系统，从前端到后端全链路说明。限流怎么做？库存如何扣减？超卖如何防止
- 如果 QPS 从 1 万涨到 100 万，方案需要如何调整
- 某接口响应突然变慢，如何排查？从哪些层面入手

### 缓存
- Redis 缓存击穿、穿透、雪崩各如何解决

### 消息队列
- 消息队列消息积压了怎么办？如何保证消息不丢失、不重复消费

### 手撕代码
- 用双向链表 + HashMap 实现 LRU 缓存，时间复杂度 O(1)，完成后处理边界情况
