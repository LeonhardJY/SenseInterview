# 华为 · 软件工程师 Java 面试真题

> 来源：牛客面经《华为OD Java面经分享（24届）》
> 岗位：Java 开发（ICT 部门 / OD 岗位）
> 流程：机考 → 综测 → HR面 → 技术一面 → 技术二面 → 主管面

## 机考（编程题）
- 山脉的个数
- 密码输入检查
- 查找众数及中位数
- 机考难度接近力扣中档题，重点在刷题

## HR 面
- 自我介绍（基本情况、兴趣爱好、性格优点、学习能力、工作经历、重点亮点）
- 为什么现在才找工作
- 为什么选择这个城市
- 家庭情况，家里人是否支持工作
- 有没有面试其他公司 / 手上有没有其他 offer

## 技术一面
### 手撕代码
- 力扣中档算法题（本地 IDE 编写并运行）

### 技术问答
- 方法重载和重写有什么区别
- 接口和抽象类的区别
- 你在项目中遇到过什么比较难解决的问题，你是怎么解决的
- Java 重构主要是为了解决什么问题
- 单例模式了解哪些，写出一个饿汉单例的代码

## 技术二面
### 手撕代码
- 算法题（重点考察代码质量与边界）

### 技术问答
- Java 的基本特性
- StringBuffer 和 StringBuilder 了解吗，区别是什么
- String 类拼接用什么方法

## 主管面
- 加入部门后需要提升哪方面的技术
- 对加班的看法
- 项目介绍，做项目过程中有无遇到什么问题、怎么解决
- 为什么想来华为
