# 腾讯 · Java 后端面试真题

> 来源：小林coding 腾讯面经系列 / 51CTO 博客
> 岗位：Java 后端开发工程师
> 考察范围：Java 基础 + Java 并发 + JVM + MySQL + Redis + 网络 + 操作系统 + 数据结构与算法

## Java 基础
- Java 集合有哪些？线程安全与线程不安全的集合分别有哪些
- 类加载机制：class 文件是如何被加载的，类加载过程分几步

## JVM
- JVM 内存模型（JMM）是怎么样的
- CMS 和 G1 有什么区别
- 谈谈你对垃圾回收的了解：什么时候发生垃圾回收，回收过程是怎样的
- Major GC 是怎么触发的

## 并发
- 对线程的理解，线程生命周期与状态流转
- 并发编程如何保证数据一致性

## MySQL
- 索引失效的场景有哪些，如何避免
- MySQL 事务隔离级别与实现原理

## Redis
- Redis 集群有没有了解过，主从、哨兵、Cluster 的区别
- 缓存与数据库一致性如何保证

## 算法
- 数据结构与算法基础（链表、树、动态规划为主）
- 手撕：常见 LeetCode 中等难度题

## 项目拷打
- 项目难点是什么，如何解决的
- 项目中的技术选型为什么这么选
