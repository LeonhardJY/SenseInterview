# SenseInterview — AI Mock Interview Platform

An AI-powered interview simulation platform that integrates voice interaction, facial expression analysis, and large language models to deliver multi-dimensional assessment and real-time feedback.

## Background

Traditional mock interview tools rely solely on text-based Q&A, making it difficult to evaluate a candidate's communication skills, emotional stability, and overall presence. SenseInterview addresses this by incorporating speech recognition and computer vision into the interview pipeline, enabling comprehensive evaluation across professional knowledge, verbal expression, logical reasoning, emotional control, and confidence level.

## Key Capabilities

- **Multi-Dimensional Assessment** — Scores cover five dimensions: professional competence, communication, logic, emotional control, and confidence, aggregated from text, voice, and video analysis.
- **Voice-Activated Interview** — Browser-based Web Speech API handles speech-to-text in real time, with automatic submission in voice mode.
- **Facial Emotion Recognition** — A dedicated DeepFace microservice analyzes the candidate's facial expressions during video-mode interviews, detecting emotions such as confidence, nervousness, calmness, and surprise.
- **Streaming LLM Responses** — All LLM interactions use Server-Sent Events (SSE) for token-by-token streaming, reducing perceived latency from approximately 5 s to 2.1 s.
- **Multi-Round Context Management** — LangChain4j conversation memory integrated with Redis session cache maintains coherent multi-turn dialogues.
- **Dynamic Interview Modes** — Three modes available: TEXT (keyboard input), VOICE (speech recognition + auto-submit), and VIDEO (camera feed + real-time emotion analysis).
- **Comprehensive Report** — Post-interview report includes dimension scores, emotion distribution timeline, and improvement suggestions generated by LLM.

## Quick Start

### Prerequisites

- Java 17+
- Node.js 18+
- Python 3.10+
- MySQL 8.0
- Redis
- DeepSeek API key

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/LeonhardJY/SenseInterview.git
cd SenseInterview

# 2. Set environment variable for LLM API key
#    Windows: setx SENSE_LLM_KEY sk-your-deepseek-api-key
#    Linux/Mac: export SENSE_LLM_KEY=sk-your-deepseek-api-key

# 3. Start MySQL and Redis services

# 4. Initialize database
#    Execute docs/database/ai_interview.sql in MySQL

# 5. Start backend services (from backend/)
cd backend
mvn spring-boot:run -pl gateway-service    # Port 8080
mvn spring-boot:run -pl ai-service         # Port 8086
mvn spring-boot:run -pl interview-service  # Port 8082

# 6. Start frontend dev server (from frontend/)
cd frontend
npm install
npm run dev                                 # Port 3000

# 7. (Optional) Start DeepFace emotion analysis service
cd backend/emotion-service
pip install -r requirements.txt
python download_model.py                    # Downloads ~500 MB model weights
python app.py                               # Port 5000
```

## Architecture Overview

```
Browser (Vue 3)
    |
    ├── /api/* ---- Gateway (Spring Cloud) ---- Service Modules
    │                                                |
    ├── /ws/* ----- Gateway ----- WebSocket Handler  |
    |                                                 |
    ├── SSE ------ /api/ai/* --- LLM Streaming --- DeepSeek API
    |                                                 |
    └── Camera --- /api/ai/analyze-emotion -- FaceAnalysisService -- DeepFace (Python)
```

- All API requests pass through the gateway, which handles JWT authentication and route forwarding.
- WebSocket connections are established per interview session for real-time progress updates.
- LLM responses are streamed via SSE, allowing token-by-token rendering in the chat interface.
- The DeepFace microservice runs as a standalone Python Flask process and is called asynchronously by the AI service.
