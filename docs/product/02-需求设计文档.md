# AI智能模拟面试评测平台需求设计文档

## 1. 项目概述

AI智能模拟面试评测平台是一套基于人工智能技术的智能面试系统，通过文字、语音、视频多模态方式模拟真实面试官，对用户进行实时面试，并在结束后生成智能评价报告。

## 2. 项目目标

### 面向求职者

-   提供真实面试训练环境
-   获取AI实时反馈
-   分析自身能力不足
-   查看历史面试报告

### 面向管理员

-   管理用户
-   管理题库
-   查看面试记录
-   审核面试结果

## 3. 系统角色

### 普通用户

功能： - 注册登录 - 创建面试 - 参与AI面试 - 查看评价报告

### 管理员

功能： - 用户管理 - 题库管理 - 面试审核 - 数据统计

### AI面试官

功能： - 自动生成问题 - 动态追问 - 分析回答 - 生成评价

## 4. 功能需求

## 4.1 用户模块

包括： - 用户注册 - 用户登录 - JWT身份认证 - 用户资料管理

## 4.2 AI面试模块

流程：

    用户进入面试
    ↓
    AI提出问题
    ↓
    用户回答
    ↓
    AI分析
    ↓
    动态追问
    ↓
    结束面试

支持模式：

  模式    说明
  ------- ----------
  TEXT    文字面试
  VOICE   语音面试
  VIDEO   视频面试

## 4.3 语音面试

流程：

    用户语音
    ↓
    ASR语音识别
    ↓
    文本分析
    ↓
    AI回复

## 4.4 视频面试

基于WebRTC实现：

-   摄像头采集
-   麦克风采集
-   实时通信
-   视频录制

## 4.5 AI评测模块

评价维度：

  指标         说明
  ------------ --------------
  专业能力     技术知识掌握
  表达能力     沟通表达
  逻辑能力     分析思考
  岗位匹配度   职位适配

输出：

-   综合评分
-   优势分析
-   不足分析
-   改进建议

## 4.6 报告模块

用户查看：

-   历史面试
-   面试问题
-   回答记录
-   AI评分
-   优化建议

## 5. 非功能需求

### 性能

-   支持多用户并发
-   实时通信低延迟
-   接口快速响应

### 安全

-   JWT认证
-   权限控制
-   数据加密

### 扩展性

支持：

-   新增AI模型
-   新增岗位
-   新增评分规则

## 6. 业务流程

``` mermaid
flowchart TD
A[用户登录] --> B[选择岗位]
B --> C[创建面试]
C --> D[AI提问]
D --> E[用户回答]
E --> F[AI分析]
F --> G[生成报告]
G --> H[查看评价]
```

## 7. 技术约束

前端： - Vue3 - Element Plus

后端： - Spring Boot - Spring Cloud

数据库： - MySQL - Redis

AI： - ASR - NLP - 大语言模型

部署： - Docker

## 8. 项目规划

第一阶段： - 用户系统 - 文字AI面试 - 自动评分

第二阶段： - 语音面试 - WebRTC视频面试

第三阶段： - AI数字人 - 企业招聘平台
