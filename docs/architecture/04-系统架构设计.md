# AI智能模拟面试评测平台系统架构设计

## 1. 架构概述

本系统采用前后端分离架构，结合微服务架构、人工智能服务以及实时通信技术，实现智能模拟面试、AI实时交互、多模态分析和自动评价。

整体架构：

```
                用户端

        Vue3 + Element Plus

                |
                |
              Nginx

                |

      Spring Cloud Gateway

                |

 ------------------------------------------------
 |              |              |                |
用户服务      面试服务       题库服务        报告服务

                |

            AI智能服务

                |

 ------------------------------------------------
 |              |              |
 MySQL        Redis          MinIO

                |

        ASR + NLP + LLM
```

# 第二层：后端业务层


采用：

```
Spring Boot + Spring Cloud
```


微服务划分：

## user-service

用户服务

职责：

- 用户注册
- 登录认证
- 权限管理


## interview-service

面试服务

职责：

- 创建面试任务
- 控制面试流程
- 管理面试状态


## question-service

题库服务

职责：

- 面试题管理
- 岗位题库
- 难度分类


## evaluation / report（并入 interview-service）

评测与报告功能已并入面试服务（interview-service），不再独立部署：

- 评测：情绪分析记录存储（`/api/evaluation/**`）
- 报告：评分生成与查询（`/api/report/**`）
- 面试任务、问答记录、综合报告聚合均在面试服务内完成


## gateway-service

网关服务

职责：

- 请求路由
- 权限验证
- 限流

# 4. WebRTC实时视频架构


## 整体流程


```
浏览器A

  |

WebRTC

  |

媒体服务器

  |

浏览器B
```


本项目：

```
面试者

 |

WebRTC Client

 |

LiveKit / Janus

 |

Spring Boot

 |

AI分析服务

```


## WebRTC流程


1. 用户进入面试房间

2. 后端创建Room

3. 返回Token

4. 浏览器加入房间

5. 建立媒体连接

6. 开始音视频传输
