# AI智能模拟面试评测平台数据库设计

## 1. 数据库概述

数据库名称：

    ai_interview

数据库用于存储用户信息、面试任务、题库、回答记录、AI分析结果以及最终评价报告。

## 2. 数据库架构关系

``` mermaid
erDiagram

SYS_USER ||--o{ INTERVIEW_TASK : creates
INTERVIEW_TASK ||--o{ INTERVIEW_RECORD : contains
INTERVIEW_RECORD ||--o{ INTERVIEW_ANSWER : has
INTERVIEW_TASK ||--o{ AI_ANALYSIS_RECORD : generates
INTERVIEW_TASK ||--|| EVALUATION_REPORT : produces

QUESTION_BANK ||--o{ INTERVIEW_TASK : provides

INTERVIEW_TASK ||--o{ VIDEO_RECORD : stores
INTERVIEW_TASK ||--o{ SPEECH_RECORD : stores
```

# 3. 核心数据表

## sys_user 用户表

用途：

存储系统用户信息。

主要字段：

  字段          说明
  ------------- ----------
  id            用户ID
  username      用户名
  password      密码
  email         邮箱
  role          角色
  status        状态
  create_time   创建时间

------------------------------------------------------------------------

## question_bank 面试题库

用途：

存储AI面试题。

字段：

  字段          说明
  ------------- ----------
  id            题目ID
  title         题目内容
  category      分类
  level         难度
  create_time   创建时间

------------------------------------------------------------------------

## interview_task 面试任务

用途：

记录一次完整模拟面试。

字段：

  字段         说明
  ------------ ----------
  id           任务ID
  user_id      用户ID
  job_name     岗位名称
  mode         面试模式
  status       状态
  start_time   开始时间
  end_time     结束时间

状态：

    CREATED
    RUNNING
    FINISHED

------------------------------------------------------------------------

## interview_record 面试过程记录

用途：

保存AI与用户每一轮交流。

字段：

  字段          说明
  ------------- --------
  id            记录ID
  task_id       任务ID
  round_num     轮次
  question      AI问题
  create_time   时间

------------------------------------------------------------------------

## interview_answer 用户回答

用途：

保存用户回答内容。

字段：

  字段          说明
  ------------- ----------
  id            回答ID
  record_id     记录ID
  answer_text   文本答案
  audio_url     语音地址
  video_url     视频地址

------------------------------------------------------------------------

## ai_analysis_record AI分析记录

用途：

保存AI模型分析结果。

字段：

  字段            说明
  --------------- ----------
  id              ID
  task_id         任务ID
  analysis_type   分析类型
  result_json     分析结果
  score           评分

------------------------------------------------------------------------

## evaluation_report 评价报告

用途：

生成最终面试报告。

评分：

-   专业能力
-   表达能力
-   逻辑能力
-   综合评分

字段：

  字段          说明
  ------------- --------
  id            报告ID
  task_id       任务ID
  total_score   总分
  summary       总结
  suggestion    建议

------------------------------------------------------------------------

## video_record 视频记录

保存WebRTC录制文件。

字段：

  字段        说明
  ----------- ----------
  id          ID
  task_id     任务ID
  video_url   视频地址

------------------------------------------------------------------------

## speech_record 语音记录

保存ASR转换数据。

字段：

  字段          说明
  ------------- ----------
  id            ID
  task_id       任务ID
  audio_url     音频地址
  text_result   识别文本

------------------------------------------------------------------------

# 4. 设计原则

1.  业务数据和AI数据分离
2.  大文件使用MinIO存储
3.  Redis缓存高频访问数据
4.  AI分析结果使用JSON扩展
5.  保留完整面试历史
